# Moto Edge 50 Guides (tank)

Custom ROM guides for Motorola Edge 50 — codename `tank` (XT2407-1 / 2 / 3). Built with [Starlight](https://starlight.astro.build).

## Dev

```sh
npm install
npm run dev    # http://127.0.0.1:4321/
```

## Content

Docs live in `src/content/docs/`. ROM pages go in `src/content/docs/roms/`. Screenshots in `src/assets/roms/<rom>/`. Shared `boot.img` mirrors go in `public/`.

```sh
npm run build  # output in dist/
```
